# Jonah Chawre — Portfolio Website

Welcome to my personal portfolio website.  
This site showcases my projects, certifications, and services in **Data Analytics, Data Science, Power BI, and Excel**.  
It’s fully responsive, optimized for desktop and mobile, and includes smooth fade-in animations on scroll.

---

## 🚀 Features
- **Responsive Design** — Works across desktop, tablet, and mobile.
- **Smooth Animations** — Fade-in effects on scroll (both directions).
- **Projects Showcase** — Interactive cards with previews and GitHub links:
  - Sales & Revenue Dashboard
  - Coffee Machine (Python)
  - Netflix Data Analytics Project
- **Certificates Section** — Visual previews of completed certifications.
- **Services Section** — Data Analytics, Data Science, Power BI, Excel.
- **Contact Form** — Integrated with [Formspree](https://formspree.io/) for easy messaging.
- **Social Links** — GitHub, LinkedIn, Fiverr icons in header and footer.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Styling:** Custom CSS + Responsive Layouts
- **Animations:** Intersection Observer + CSS transitions
- **Forms:** Formspree
- **Hosting:** GitHub Pages / Netlify / Vercel
