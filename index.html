Services

Data Analytics

I turn messy data into clear answers. Typical workflow: define the question, gather and clean data, analyze with Python/Excel/SQL, and present results in visuals that make sense on first glance. Expect reproducible notebooks, smart feature selection, and simple dashboards that highlight trends, anomalies, and drivers. I’m deliberate about assumptions and always include plain‑English summaries so non‑tech stakeholders know what changed and why. Deliverables can include a cleaned dataset, a notebook or scripts, and a shareable report.

Data Scientist

When you need prediction or pattern‑finding, I build small, reliable models. That means tidy data pipelines, baseline metrics, and careful validation. I favor simpler models first (logistic/linear, tree‑based) before reaching for heavier architectures. The goal isn’t a leaderboard flex; it’s a model you can trust and maintain. I document trade‑offs, provide confusion matrices or error breakdowns, and include a one‑page “how to run it” guide so hand‑off is painless.

Power BI

Clean, fast dashboards that load quickly and answer real questions. I build semantic models with proper relationships and measures, write clean DAX, and design with layout rules that keep the signal obvious. I add drill‑through, tooltips, and bookmarks when they help, not just because they’re shiny. You’ll get a .pbix file, a dataset with refresh instructions, and a short Loom or doc explaining how to update and distribute the report.

Excel

Solid spreadsheets without chaos. I build structured workbooks with tables, named ranges, data validation, and formulas that won’t explode the first time someone pastes new rows. I can convert ad‑hoc sheets into a maintainable model, add pivot tables and charts, and leave behind a quick guide so anyone on the team can extend it safely.
